# 🚀 ATVoice Voice Assistant

¡Hola! Este es mi asistente de voz inteligente creado en **Kodular** a mis 9 años. La aplicación aprovecha el hardware real del teléfono para automatizar tareas por voz y monitorear el estado del celular.

---

## 🛠️ Funciones Principales

* **Reconocimiento de Voz**: Escucha tus comandos para abrir aplicaciones externas como Google, YouTube y WhatsApp a través de `ActivityStarter`.
* **Historial de Comandos**: Guarda y muestra dinámicamente en pantalla una lista de las órdenes que has dictado.
* **Control por Impacto**: Usa el sensor del **Acelerómetro** para reaccionar físicamente cuando sacudes el teléfono (`Acelerómetro1.Agitar`).
* **Alerta Inteligente de Batería**: Monitorea el hardware del dispositivo al iniciar y despliega un cuadro de diálogo crítico si la batería baja del 20%.

---

## 🧩 Bloques y Lógica Utilizada

El proyecto incluye lógica avanzada de programación visual:
* Variables globales y creación de listas dinámicas vacías.
* Estructuras condicionales independientes (`si... entonces`).
* Comparaciones lógicas y operadores matemáticos (`≥`).
* Componente de **Texto a Voz** (`TextoAVoz1`) para reproducir mensajes.

---

## 📥 Archivos del Proyecto

* **`.aia`**: Archivo fuente con todos mis bloques y diseño para importar en Kodular.
* **`.apk`**: Aplicación compilada lista para instalar en dispositivos Android.
